# v1/containers/{containerId}/schedule-of-values

Creates a new schedule of values (SOV) item for the given project as a child of an existing SOV item.
This endpoint can only be used to create sub schedule of value items as root items can only be created when the budgets are allocated to the contract.

  Note that this endpoint is compatible with both BIM 360 and Autodesk Construction Cloud (ACC) projects.
