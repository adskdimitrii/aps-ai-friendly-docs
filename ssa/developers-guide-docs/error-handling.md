# Error Handling

When an error occurs, APS typically provides additional information about what went wrong in the response body. The structure of the response body depends on whether the error was generated by the Secure Service Account (SSA) service or the Authentication service.

The response body received for a request sent to the Secure Service Account (SSA) service contains the following error structure:

```
{
 "title": "...",
 "detail": "..."
}

```

Where
- `title` is a short, human-readable summary of the problem that occurred.
- `detail` is a human-readable explanation specific to this occurrence of the problem. It may include information on what you should do next to resolve the issue.

Please refer to the [Authentication Service Error Handling section](../../oauth/developers-guide-docs/error_handling.md) for the list of responses, codes and structure thrown by the Authentication service.
