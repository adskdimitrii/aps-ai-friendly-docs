## Column Definition Types

The ACC Data Schema tables are often delivered in a "lowest common denominator" format (i.e. CSV) and
 as a result the column type definitions are limited to the following:

- boolean
- date: string
- enum: string
- number
- string
- string: UUID *(xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx)*
- string: null
- time *(HH:MM:SS) (UTC)*
- timestamp: SQL *(YYYY-MM-DD HH:MM:SS.mmm) (UTC)*
