# About this Walkthrough

This walkthrough guides you through the process of executing a MAXScript file with *3dsmaxbatch.exe* using the Automation API.
This walkthrough does not teach you how to write a script for 3ds Max (MAXScript or python) or how to use the *3dsmaxbatch.exe* interface.
We assume that you already know how to write scripts for 3ds Max. If this is not the case, we recommend the following:

- [MAXscript Reference](https://help.autodesk.com/view/MAXDEV/2025/ENU/?guid=GUID-F039181A-C072-4469-A329-AE60FF7535E7)
- [About 3ds Max Batch](https://help.autodesk.com/view/3DSMAX/2025/ENU/?guid=GUID-0968FF0A-5ADD-454D-B8F6-1983E76A4AF9)

The techniques used in this walkthrough are generic. Hence, you can use your own MAXScript and 3ds Max files for this walkthrough.
However, if you do not wish to use your own script and/or 3ds Max file, you can use the samples from [here](https://github.com/autodesk-platform-services/aps-tutorial-postman/tree/master/DA43dsMax/walkthrough_data).

The walkthroughs on the APS developer portal are based on [cURL](https://curl.haxx.se/). However, if you prefer using [Postman](https://www.getpostman.com/) over [cURL](https://curl.haxx.se/), you can follow a [Postman version of this walkthrough](https://github.com/autodesk-platform-services/aps-tutorial-postman/tree/master/DA43dsMax).

## [Postman walkthrough](#postman-walkthrough)

[Postman](https://www.getpostman.com/) is a popular tool that provides an easy-to-use interface to send HTTP requests. [The Postman walkthrough](https://github.com/autodesk-platform-services/aps-tutorial-postman/tree/master/DA43dsMax) comes with a collection of pre-populated HTTP requests that you can modify.
This gives you the ability to experiment without having to write a single line of code.

On the Postman Collection, requests are grouped by task. The group has the same name as the corresponding task in the cURL walkthrough on the APS developer portal.
