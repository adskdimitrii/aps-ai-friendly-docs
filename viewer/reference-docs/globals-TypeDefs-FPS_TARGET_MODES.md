# _TARGET_MODES

Modes to set the FPS target when progressive rendering is enabled.

# Properties

| LOW   number | sets the FPS target to 6. |
| --- | --- |
| MODERATE   number | sets the FPS target to 15. |
| MEDIUM   number | sets the FPS target to 30. |
| HIGH   number | sets the FPS target to 60. |
