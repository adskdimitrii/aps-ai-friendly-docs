# DifferenceType

[](#) Enum representing the type of change

## [Valid Values](#valid-values)

| Value | Description |
| --- | --- |
| ADDITION | An element, property, or nested value was added. |
| MODIFICATION | An element, property, or nested value was modified. |
| REMOVAL | An element, property, or nested value was removed. |

## [Where Used](#where-used)

| Object/Input | Field | Description |
| --- | --- | --- |

| [PropertyDifference](objects-propertydifference.md) | `type`. | Represents a Property Difference type |
