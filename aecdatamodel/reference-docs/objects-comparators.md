# Comparators

[](#) Valid comparators when filtering by a value

## [Valid Values](#valid-values)

| Value | Description |
| --- | --- |
| CASE_SENSITIVE | Case sensitive |
| CONTAINS | Contains |
| STARTS_WITH | Starts with |
| ENDS_WITH | Ends with |
| GREATER_THAN | Greater than |
| LESS_THAN | Less than |
| GREATER_THAN_EQUAL_TO | Greater than or equal to |
| LESS_THAN_EQUAL_TO | Less than or equal to |
| NOT_EQUAL | Not equal to |

## [Where Used](#where-used)

| Object/Input | Field | Description |
| --- | --- | --- |
| [valuecomparatorinput](inputs-valuecomparatorinput.md) | `comparator`. | Comparator to apply |
