# Point

[](#)

Represents a point in 3D space.

## [Fields](#fields)

| x*   [Float!](scalars.md) `non-null` | The X-coordinate of the point. |
| --- | --- |
| y*   [Float!](scalars.md) `non-null` | The Y-coordinate of the point. |
| z*   [Float!](scalars.md) `non-null` | The Z-coordinate of the point. |

* Required
