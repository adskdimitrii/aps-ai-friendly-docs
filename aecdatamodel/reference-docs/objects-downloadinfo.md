# DownloadInfo

[](#)

Represents information required to download geometry data from a URL.

## [Fields](#fields)

| url*   [String!](scalars.md) `non-null` | The URL from which the geometry data can be downloaded. |
| --- | --- |
| objectId*   [ID!](scalars.md) `non-null` | The object ID associated with the download. |

* Required
